# Student Result Management System

## Project Description

Student Result Management System is a desktop application developed using Python, Tkinter, and MySQL.

The system helps to manage student examination results in an easy and organized way.

## Technologies Used

- Python
- Tkinter
- MySQL
- MySQL Connector for Python

## Features

- User Login
- Dashboard
- Add Student Result
- View Student Records
- Search Student Records
- Update Student Result
- Delete Student Result
- Calculate Total Marks
- Calculate Percentage
- Calculate Grade
- Logout

## Database

Database Name:

`student_result`

Table Name:

`students`

The application uses MySQL to store and manage student result records.
